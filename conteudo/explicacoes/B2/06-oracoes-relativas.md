<b>O QUE É E QUANDO USAR</b>
Orações relativas (<i>relative clauses</i>) servem para conectar duas ideias em uma só frase. Elas adicionam informações sobre um substantivo (pessoa, coisa, lugar) que já foi mencionado, evitando repetição e deixando a comunicação mais fluida.

<b>AS FORMAS</b>
Existem dois tipos de <i>relative clauses</i>:
- <i>Defining clauses</i>: Trazem informação <b>essencial</b> para entender de quem ou do que estamos falando. Não usam vírgulas.
- <i>Non-defining clauses</i>: Trazem informação <b>extra</b>, que poderia ser removida sem alterar o sentido principal. Ficam sempre entre vírgulas.

Os pronomes que iniciam essas orações (<i>relative pronouns</i>) são:
- <i>who</i>: para pessoas.
- <i>which</i>: para coisas e animais.
- <i>that</i>: para pessoas ou coisas (apenas em <i>defining clauses</i>).
- <i>whose</i>: para indicar posse (de quem é algo).
- <i>where</i>: para lugares.
- <i>when</i>: para tempo (dia, ano, momento).

<b>EXEMPLOS</b>
- <i>The woman <b>who</b> works with me is from Canada.</i>
(A mulher que trabalha comigo é do Canadá.)
<i>Info essencial, sem vírgulas: defining clause.</i>

- <i>My car, <b>which</b> is very old, needs a new battery.</i>
(Meu carro, que é muito velho, precisa de uma bateria nova.)
<i>Info extra, entre vírgulas: non-defining clause.</i>

- <i>That's the boy <b>whose</b> father is a famous actor.</i>
(Aquele é o garoto cujo pai é um ator famoso.)

- <i>This is the park <b>where</b> we had our first picnic.</i>
(Este é o parque onde fizemos nosso primeiro piquenique.)

<b>ERROS COMUNS</b>
O erro mais comum é usar <i>that</i> em <i>non-defining clauses</i> (as que ficam entre vírgulas). Lembre-se: se tem vírgula, não pode usar <i>that</i>.
errado: <i>My brother, <b>that</b> lives in Rio, is a doctor.</i>
o certo é: <i>My brother, <b>who</b> lives in Rio, is a doctor.</i>
A informação "<i>who lives in Rio</i>" é extra. Se você a remover, a frase "<i>My brother is a doctor</i>" ainda faz sentido. Por isso, ela vem entre vírgulas e não pode usar <i>that</i>.

Outro erro é usar <i>which</i> para se referir a pessoas.
errado: <i>The girl <b>which</b> is sitting there is my sister.</i>
o certo é: <i>The girl <b>who</b> is sitting there is my sister.</i>
Para pessoas, o pronome correto é sempre <i>who</i> (ou <i>that</i>, se for uma <i>defining clause</i>).

<b>RESUMO</b>
Use <i>who</i> (pessoas) ou <i>which</i> (coisas) para dar mais detalhes; se a informação for essencial e sem vírgulas, <i>that</i> também serve. 💡
