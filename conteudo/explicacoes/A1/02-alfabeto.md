<b>O QUE É E QUANDO USAR</b>
O alfabeto em inglês tem as mesmas 26 letras que o nosso, mas o NOME de cada letra é diferente. Saber os nomes é essencial para soletrar palavras em voz alta, como seu nome, sobrenome ou e-mail, quando alguém não entende o que você disse.

<b>AS FORMAS</b>
Este é o nome de cada letra em inglês. Para perguntar como se soletra, diga: <i>How do you spell it?</i>

- A (se pronuncia <i>ei</i>)
- B (se pronuncia <i>bi</i>)
- C (se pronuncia <i>si</i>)
- D (se pronuncia <i>di</i>)
- E (se pronuncia <i>i</i>)
- F (se pronuncia <i>éf</i>)
- G (se pronuncia <i>dji</i>)
- H (se pronuncia <i>eitch</i>)
- I (se pronuncia <i>ai</i>)
- J (se pronuncia <i>djei</i>)
- K (se pronuncia <i>kei</i>)
- L (se pronuncia <i>él</i>)
- M (se pronuncia <i>ém</i>)
- N (se pronuncia <i>én</i>)
- O (se pronuncia <i>ou</i>)
- P (se pronuncia <i>pi</i>)
- Q (se pronuncia <i>kiu</i>)
- R (se pronuncia <i>ar</i>)
- S (se pronuncia <i>és</i>)
- T (se pronuncia <i>ti</i>)
- U (se pronuncia <i>iu</i>)
- V (se pronuncia <i>vi</i>)
- W (se pronuncia <i>dá-bliu</i>)
- X (se pronuncia <i>éks</i>)
- Y (se pronuncia <i>uai</i>)
- Z (se pronuncia <i>zi</i>)

As vogais (<i>vowels</i>) são: <b>A, E, I, O, U</b>.

<b>EXEMPLOS</b>
- <i>How do you spell 'book'?</i> (Como se soletra 'book'?)
- <i>B-O-O-K.</i>

- <i>My name is Ana. A-N-A.</i> (Meu nome é Ana. A-N-A.)

- <i>How do you spell 'water'?</i> (Como se soletra 'water'?)
- <i>W-A-T-E-R.</i>

- <i>My last name is Silva. S-I-L-V-A.</i> (Meu sobrenome é Silva. S-I-L-V-A.)

<b>ERROS COMUNS</b>
O erro mais comum é confundir o <b>NOME</b> da letra com o <b>SOM</b> que ela faz dentro de uma palavra. Lembre-se: para soletrar, você deve usar o NOME da letra.

Por exemplo, para soletrar a palavra <i>CAR</i> (carro):
errado: dizer o som de cada letra, como falamos em português.
o certo é: dizer o NOME de cada letra em inglês: <i>C-A-R (si-ei-ar)</i>.

Outro exemplo: a letra <b>E</b>. O nome dela é <i>i</i>. Na palavra <i>red</i> (vermelho), o som dela é <i>é</i>.
errado: soletrar <i>red</i> dizendo R-É-D.
o certo é: soletrar <i>red</i> dizendo o nome das letras: <i>R-E-D (ar-i-di)</i>.

<b>RESUMO</b>
Para soletrar em inglês, sempre diga o NOME de cada letra, não o som que ela faz na palavra.
