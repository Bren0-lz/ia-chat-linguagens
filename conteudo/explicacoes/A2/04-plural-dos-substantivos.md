<b>O QUE É E QUANDO USAR</b>
O plural é a forma que usamos para falar de mais de uma coisa, pessoa ou lugar. Em inglês, a maioria das palavras muda um pouquinho para mostrar que está no plural, geralmente adicionando uma letra no final.

<b>AS FORMAS</b>
- Para a maioria das palavras, adicione <b>-s</b>.
<i>car → cars</i> (carro → carros)
<i>book → books</i> (livro → livros)

- Para palavras que terminam em <b>-s, -ss, -sh, -ch, -x, -o</b>, adicione <b>-es</b>.
<i>bus → buses</i> (ônibus → ônibus)
<i>box → boxes</i> (caixa → caixas)
<i>potato → potatoes</i> (batata → batatas)

- Para palavras que terminam em <b>consoante + y</b>, tire o <b>y</b> e adicione <b>-ies</b>.
<i>city → cities</i> (cidade → cidades)
<i>family → families</i> (família → famílias)

- Se a palavra terminar em <b>vogal + y</b>, só adicione <b>-s</b>.
<i>boy → boys</i> (menino → meninos)
<i>day → days</i> (dia → dias)

- Para palavras que terminam em <b>-f</b> ou <b>-fe</b>, troque por <b>-ves</b>.
<i>leaf → leaves</i> (folha → folhas)
<i>knife → knives</i> (faca → facas)

- E existem os plurais <b>irregulares</b>, que mudam completamente. Você precisa memorizar estes:
<i>man → men</i> (homem → homens)
<i>woman → women</i> (mulher → mulheres)
<i>child → children</i> (criança → crianças)
<i>foot → feet</i> (pé → pés)
<i>tooth → teeth</i> (dente → dentes)
<i>person → people</i> (pessoa → pessoas)
<i>mouse → mice</i> (rato → ratos)
<i>fish → fish</i> (peixe → peixes)

<b>EXEMPLOS</b>
- I have two <b>dogs</b> and one cat.
<i>Eu tenho dois cachorros e um gato.</i>

- We need to buy some <b>potatoes</b> for dinner.
<i>Nós precisamos comprar algumas batatas para o jantar.</i>

- Those <b>women</b> are my friends.
<i>Aquelas mulheres são minhas amigas.</i>

- There are many beautiful <b>cities</b> in Brazil.
<i>Existem muitas cidades bonitas no Brasil.</i>

<b>ERROS COMUNS</b>
O erro mais comum é colocar <b>-s</b> em palavras com plural irregular. Lembre-se que elas têm uma forma especial e não seguem a regra geral.

Errado: I see two <i>childs</i> playing.
O certo é: I see two <i>children</i> playing.

A palavra <i>child</i> é irregular. O plural dela não é formado com <b>-s</b>, e sim com a forma especial <b>children</b>. O mesmo vale para <i>men, women, people</i>, etc.

<b>RESUMO</b>
Para o plural, adicione <b>-s</b>, mas memorize as terminações especiais e a lista de palavras irregulares.
